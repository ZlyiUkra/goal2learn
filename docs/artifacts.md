# Артефакти курсу

Сторінки, на які спирається навчання. Обидві приватні: відкриваються лише з акаунта власника.

## Основне

- [Шлях Фулстек](https://claude.ai/artifact/BUZaCYE89vd3BfB9eKTmYx): головний маршрут лінійки. React, потім NestJS,
  потім Next.js, один проєкт на трьох планах. Етап 1 (React, повний шлях) - 67 днів, фаза 0 - перші 12. Для кожного
  дня є мета, пояснення, що читати, які сервери документації потрібні, що зробити, як перевірити себе й типова
  пастка. Прогрес зберігається на самій сторінці, не в репозиторії.

## До окремих уроків

- [Рівність і копіювання](https://claude.ai/artifact/MV2PmAJGC8B5ENPb6RLH8m): теорія до фази 0, дня 1
  (значення й посилання). `Object.is()`, spread, `structuredClone()`, розділ 2.7 HTML Standard, що обирати.
- [Spread, rest і деструктуризація](https://claude.ai/artifact/7CufLP1wWQpKps6KfwDBsP): довідка до фази 0, дня 1
  (значення й посилання). Три ролі знака `...`, поверхнева копія, крайні випадки, підводні камені.

## Як проходить день

- День беремо з "Шляху Фулстек": читаємо вказане, піднімаємо потрібні сервери документації, робимо вправу.
- Вправа дня лежить у `drills/`. Файл `f0-d01.js` - фаза 0, день 1. Наступні дні називаємо за тим самим зразком.
- Перевірки на `node:assert` стоять нижче рядка "нічого не змінюйте нижче цього рядка". Запуск:
  `node drills/f0-d01.js`. Успіх - останній рядок "Усі перевірки пройдені" і код виходу 0.
